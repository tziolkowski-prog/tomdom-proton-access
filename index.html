Bezpieczeństwo i konfiguracja

Połączenie wykorzystuje Google Identity Services i Gmail API. Aplikacja żąda dostępu do odczytu poczty oraz wysyłania wiadomości. Nie ma dostępu do hasła Google. Identyfikator OAuth jest publicznym identyfikatorem aplikacji, nie sekretem.

W Google Cloud trzeba włączyć Gmail API, skonfigurować ekran zgody OAuth i utworzyć klienta OAuth typu aplikacja internetowa. W autoryzowanych źródłach JavaScript dodaj dokładny adres GitHub Pages tej aplikacji.
